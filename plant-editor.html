Load your JSON file to get started. Search the index on the left, click a plant, edit its record card, then save your changes — directly to GitHub or as a downloaded file.

Connect to GitHub

To save changes directly to your repo, the editor needs a personal access token. The token stays in your browser only — it's never saved to a file or sent anywhere except GitHub's API.

Need a token? Go to GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Create one scoped to just this repo with Contents: Read and write permission. Paste it here — it's stored only for this browser session.
